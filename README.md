# House Price Prediction using Machine Learning

A beginner-friendly machine learning project that predicts house prices based on house size using Python and Linear Regression.

## Project Overview

This project demonstrates the fundamental steps of a machine learning workflow, from preparing a dataset to training, evaluating, and using a model to make predictions.

## Technologies Used

- Python
- pandas
- scikit-learn
- Google Colab

## Dataset

The initial learning dataset contains house sizes in square feet and corresponding prices in lakhs of rupees.

**Note:** This project uses a small, synthetic dataset for learning purposes. It is not intended for real-world property valuation.

## Machine Learning Workflow

1. Create and load the dataset.
2. Separate features and target values.
3. Split the data into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate predictions using Mean Absolute Error (MAE).
6. Predict the price for a new house.

## How to Run

Open the notebook in Google Colab or run the Python code in an environment with the required libraries installed.

Install dependencies with:

```bash
pip install pandas scikit-learn
```
